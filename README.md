# 🔍 AI Code Reviewer & Security Scanner

A lightweight, high-performance Python utility designed to statically analyze scripts for security vulnerabilities, bad practices, and performance bottlenecks before they hit production.

## 🚀 Features
- **Security Scanning:** Detects dangerous functions (such as `eval()`) to prevent remote code execution.
- **Performance Tips:** Flags suboptimal patterns (like heavy `print()` usage) in favor of scalable logging.
- **Structural Insights:** Monitors file size and code complexity to encourage modular architecture.
- **100% Open Source:** Clean, readable, and easy to extend.
